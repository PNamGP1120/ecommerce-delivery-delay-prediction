# E-Commerce Delivery Delay Prediction

## Overview

## Business Problem

The goal of this project is to build a machine learning
system that identifies e-commerce orders at risk of late
delivery so that operational teams can intervene earlier.

## Prediction Point

Predictions are assumed to be generated at order approval
time. Therefore, only information available at or before
order_approved_at may be used as model input.
